## 🏳️‍⚧️ About me

- 🧑‍💻 Exploring software, hardware, game development, retro systems, emulation, and custom firmware.
- 🌍 Fluent in **German** and **English**.
- 🧰 Working across Rust, Java, C++, C#, Python, Scala, Lua, JavaScript, ActionScript, BASIC, HTML, CSS, Processing, Markdown, and San Andreas Script.
